## 💡 Sobre

Este repositório reúne toda a minha jornada de aprendizado em front-end — desde os primeiros exercícios com tags HTML até projetos completos com CSS responsivo e JavaScript interativo. Cada pasta é um módulo independente, servindo como referência e portfólio de evolução.

<br>

## ▶️ Como Executar

Nenhuma instalação necessária para os projetos HTML/CSS/JS.

```bash
# 1. Clone o repositório
git clone https://github.com/Paulinhuph/HTML-CSS-JS-HUB.git

# 2. Abra qualquer projeto no navegador
#    Basta abrir o arquivo index.html diretamente,
#    ou usar a extensão Live Server no VS Code.

# 3. Para os arquivos .js de estudo, execute com Node.js:
node JS-Estudos-Sintaxe/variaveis.js
```

> **💡 Dica:** Use a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) no VS Code para recarregamento automático ao salvar.
