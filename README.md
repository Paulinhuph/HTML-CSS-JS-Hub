# 🎨 Estudos — HTML, CSS & JavaScript

Repositório dedicado aos meus estudos práticos de desenvolvimento front-end. Aqui você encontra experimentos, exercícios e projetos visuais construídos com as tecnologias fundamentais da web.

---

## 🗂️ Estrutura

Cada pasta representa um projeto ou exercício independente, com seus próprios arquivos HTML, CSS e JS. Os projetos variam em complexidade — desde experimentos simples até interfaces mais elaboradas.

```
/
├── jornada-viagens/
│   ├── index.html
│   ├── style.css
│   └── script.js
├── Pesquisa-Culturama/
│   └── ...
└── ...
```

## 🛠️ Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

- **HTML** — estrutura e semântica das páginas
- **CSS** — estilização, layouts (Flexbox & Grid), animações e responsividade
- **JavaScript** — interatividade, manipulação do DOM e lógica de interface

---

## 🎯 Objetivo

Praticar e consolidar os fundamentos do front-end através de projetos visuais, desenvolvendo habilidades em:

- Estruturação semântica de páginas
- Design responsivo e adaptável
- Animações e transições com CSS
- Interatividade e dinamismo com JS puro
- Boas práticas de organização de código

---

## 🚀 Como visualizar

Nenhuma instalação necessária. Basta abrir o arquivo `index.html` de qualquer projeto diretamente no navegador, ou usar uma extensão como **Live Server** (VS Code) para recarregamento automático.

---

## 📌 Observações

- Os projetos são feitos para fins educacionais, sem dependências externas obrigatórias
- O foco está na prática e experimentação — qualidade visual e criatividade são bem-vindas
- Cada projeto pode estar em diferentes estágios de conclusão
